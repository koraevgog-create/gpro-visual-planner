# GPRO Visual Planner

Интерактивная карта целей, проектов и задач на React + React Flow.

## Запуск

```bash
npm install
npm run dev
```

## GitHub Pages

В Settings → Pages → Build and deployment выберите **GitHub Actions**. Workflow `.github/workflows/deploy.yml` соберёт проект при пуше в main.

URL после публикации: https://koraevgog-create.github.io/gpro-visual-planner/

## Версия 0.1

- Редактирование заголовка, типа, статуса и заметок.
- Добавление дочерних и корневых узлов.
- Перетаскивание, приближение, миникарта.

**Важно:** данные пока не синхронизируются между устройствами. Перед очисткой браузера экспортируйте резервную копию. Ветка `main` — рабочая, используйте PR для крупных изменений.

## Структура

- `src/data/` — начальная карта.
- `src/lib/` — хранение и обмен данными.
- `src/components/` — независимые элементы интерфейса.
- `src/App.jsx` — единое управление состоянием.
- `src/styles.css` — стили.
- `.github/workflows/` — публикация.
